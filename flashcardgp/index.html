Các bước thiết kế Flashcard
1
Thông tin học thuật: Điền đầy đủ thông tin học thuật tại mục I để AI hiểu ngữ cảnh.
2
Nội dung & Hình thức: Nhập dữ liệu (tay, Upload, AI gợi ý), chọn kiểu game và phong cách (màu sắc).
3

4
Tạo Game: Dán Prompt vào Gemini/ChatGPT/Claude để nhận mã HTML và lưu lại dưới dạng "têngame.html".
5
Trải nghiệm: Mở game bằng trình duyệt web. Nếu chọn game Mảnh ghép bí ẩn, lưu file ảnh bí ẩn và file game cùng thư mục.
